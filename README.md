# aerial2cad app

The browser app from the private `troyhome/aerial2cad` repo, published with GitHub Pages:
https://troyhome.github.io/aerial2cad-app/

`index.html` is a copy of `dist/aerial2cad.html` there. Do not edit it here: change the
private repo, rebuild (`python3 web/build.py`) and run `web/publish.sh`.
